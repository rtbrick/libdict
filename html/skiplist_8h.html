Detailed Description

Skip list [Pugh 1990].

A sorted linked list with additional express links on randomly chosen levels, so insert, search and remove take expected O(log n) time. It supports the near searches but not selecting the nth element. Levels come from random(), which libdict does not seed.

dict_insert_result skiplist_insert ( skiplist * list,
void * key )

Insert |key| unless an equal key is present.

Returns {&datum, true} for a new key, whose datum starts as NULL; the list stores the |key| pointer itself, it does not copy the key. If an equal key is present, returns {&datum, false} with that key's datum, and |key| is not stored and still belongs to the caller. Returns {NULL, false} if memory cannot be allocated.

Compute the histogram of link counts of the skiplist.

For 0 <= x < |ncounts|, |counts|[x] will be set to the number of nodes with x links, and the maximal link count will be returned. If the return value is greater than or equal to |ncounts|, not all link counts could be stored in |counts| (i.e. the array was not large enough).

◆ skiplist_new()

skiplist * skiplist_new ( dict_compare_func cmp_func,
unsigned max_link )

Create an empty skip list that orders keys with |cmp_func| (must not be NULL).

|max_link| is the number of levels in the list. It is clamped into the usable range [2, 32]: a node receives at most max_link - 1 links, so fewer than 2 levels could not link anything. Returns NULL if memory cannot be allocated.
