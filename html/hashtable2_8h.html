Detailed Description

Hash table with open addressing and linear probing.

Insert, search and remove take expected O(1) time. The table grows automatically when an insert finds the number of elements at two thirds of the number of slots or more. It is not sorted: there are no near searches, no selection of the nth element, and no iterator comparison, and iteration visits the elements in an unspecified order. A removal moves other elements between slots, so it invalidates every iterator over the table.

◆ hashtable2_insert()

dict_insert_result hashtable2_insert ( hashtable2 * table,
void * key )

Insert |key| unless an equal key is present.

Returns {&datum, true} for a new key, whose datum starts as NULL; the table stores the |key| pointer itself, it does not copy the key. If an equal key is present, returns {&datum, false} with that key's datum, and |key| is not stored and still belongs to the caller. Returns {NULL, false} if memory cannot be allocated. May grow the table first, which invalidates every iterator over it; inserting a key that is already present never does.

◆ hashtable2_resize()

bool hashtable2_resize ( hashtable2 * table,
unsigned size )

Rehash the table into at least |size| slots, rounded up as in hashtable2_new().

Returns true on success, or if the table already has that many slots. Returns false, leaving the table unchanged, if memory cannot be allocated, if fewer slots than elements are requested, or if the slot array would not fit in a size_t. A successful resize invalidates every iterator over the table.
